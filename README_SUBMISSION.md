# HavenCare Hospital Management System

ICT726 Assignment 3 submission package. HavenCare is a fictional, framework-free static hospital website built with original HTML5, CSS3 and vanilla JavaScript.

## Package contents

- `website/` — six HTML pages and all local CSS, JavaScript and WebP media
- `report/HavenCare_Development_Report.docx` — editable development report
- `report/HavenCare_Development_Report.pdf` — print-ready report
- `report/evidence/` — wireframes and final desktop/mobile visual previews
- `MEDIA_ATTRIBUTION.md` — media inventory and AI-use disclosure

## Preview the website

The simplest option is to open `website/index.html` in a modern browser. For a closer hosting test, serve the `website` folder with any local static server and open its local URL.

Recommended checks:

1. Follow every navigation link on desktop and mobile widths.
2. Use Tab and Shift+Tab to confirm the skip link, menu, buttons, filters, gallery and form are reachable.
3. Filter the care team and confirm the result count changes.
4. Open gallery thumbnails; test Previous, Next, Escape and arrow keys.
5. Submit the appointment form empty, then with fictional valid information. Confirm errors are specific and success says nothing was sent or stored.
6. Confirm the reduced-motion preference disables non-essential motion.

## Publish the static site

Upload the **contents** of `website/` to the root of a static host so that `index.html` is at the published root. GitHub Pages, Netlify and similar static hosts are suitable. After publishing, repeat the checks above using the final URL.

## Privacy and scope

This is a front-end educational prototype, not a clinical system. It has no database, authentication, analytics, cookies, tracking or network form endpoint. Use fictional information when testing. The visible emergency information is general Australian signposting and the site does not provide medical advice.
